# PE — Physical and Environmental Protection

**Fully inherited** from the hosting cloud's FedRAMP authorisation:

- **AWS GovCloud (US)** — PE-1 through PE-23 are inherited from AWS's
  Provisional Authorization for FedRAMP High; documented in the AWS
  FedRAMP package available to authorised customers.
- **Azure Government** — same, via Azure's GovCloud authorisation.
- **On-prem agency datacentre** — the agency's physical security
  programme satisfies the PE family; documented in the agency-specific
  SSP wrapper.

The chassis itself has no physical components; the container hosts run
on the cloud platform's hypervisors.
